# Khaire Hospital - Healthcare Website Landing Page

A modern, responsive, and user-friendly healthcare website landing page built with HTML and CSS. This project showcases a professional hospital website design with smooth navigation, beautiful UI components, and comprehensive information about medical services.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Smooth Navigation**: Smooth scrolling anchor links in the navbar for easy navigation to different sections
- **Modern UI**: Clean and professional design with attractive color scheme and typography
- **Sections Included**:
  - Header with hero section and appointment booking form
  - Services section highlighting laboratory tests, health checks, and dentistry
  - About Us section with hospital information
  - Why Choose Us section with key benefits and features
  - Doctors section showcasing medical professionals with their specialties
  - Appointment booking section for patient convenience
  - Contact Us information with location and contact details
  - Footer with comprehensive links and social media

## Technologies Used

- **HTML5**: Semantic markup and proper structure
- **CSS3**: Modern styling with flexbox and responsive design
- **Icons**: Remix Icon library for beautiful icons
- **Google Fonts**: Poppins font family for modern typography

## How to Use

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Navigate through different sections using the navbar
4. The page features smooth scrolling for better user experience

## Customization

You can easily customize:
- Colors: Update CSS variables in `:root` selector in `styles.css`
- Content: Edit text and information directly in `index.html`
- Images: Replace images in the `assets/` folder
- Links: Update navigation links and social media URLs
